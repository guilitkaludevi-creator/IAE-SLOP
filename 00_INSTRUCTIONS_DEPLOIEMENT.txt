GUIDE DE DÉPLOIEMENT RAPIDE SUR GITHUB (10 SECONDES)
===================================================

1. Rendez-vous sur votre dépôt GitHub dans votre navigateur :
   https://github.com/guilitkaludevi-creator/IAE-SLOP/upload/main

2. Sélectionnez TOUS les fichiers présents dans ce dossier (Ctrl + A)
   et glissez-déposez-les directement sur la page GitHub.

3. En bas de page sur GitHub, cliquez sur le bouton vert "Commit changes".

4. Votre site est déployé en 30 secondes sur :
   https://guilitkaludevi-creator.github.io/IAE-SLOP/
